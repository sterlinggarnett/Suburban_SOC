## Late catch — exec bit (found at the commit gate)

The first draft invoked the preflight as `"${SCRIPT_DIR}/capture_iface_preflight.sh"`,
relying on the executable bit. This repo sets `core.fileMode=false` and tracks every
`scripts/setup/` script as mode `100644` (`host_capture.sh`,
`redeploy_systemd_units.sh`, `setup_branch_protection.sh` all confirmed), so the exec
bit exists only on a host that happened to chmod it locally — a fresh clone would get
`Permission denied` and the capture lane would refuse to start. It worked here only
because this session had chmod'd the file.

Fixed to `/bin/bash "${SCRIPT_DIR}/capture_iface_preflight.sh" "$IFACE"`, matching the
unit's own `ExecStart=/bin/bash ${SOC_REPO}/scripts/setup/host_capture.sh`. Proven both
ways at mode 644: direct execution → `Permission denied`, `/bin/bash` → exit 0.
Regression test `test_the_preflight_is_invoked_through_an_explicit_interpreter`.
